# 现金流与经营储备

先明确公司模式、记账币种、核对期间和数据截止日。读取平台指标及对应账户、资金记录和订阅，按需要分页查询，不把一页记录当作完整主账。

真实经营缺少银行、支付、账单或订阅数据时，请用户提供实际资料或所需的最小读取授权。访问凭据留在 Agent 的安全存储或专用连接配置中。模拟记录明确标注虚构来源；缺少市场成本依据时，说明情景假设或保留未知。

现金余额由期初和已发生流入、流出形成。核对来源、日期、账户及币种；内部转账不能重复计算公司净流入。经营收付款与资本投入、融资分别观察。更正通过追加或冲销保存，不抹除原依据。

订阅规模适用时，MRR 按生效固定订阅月归一化，ARR 为 MRR × 12；二者不等于已到账现金。免费、试用、一次性收入和税款不能混入固定订阅规模。没有完整会计依据时，不从现金流推断利润。

现金可维持周期按服务的确定性口径读取：可用现金与最近三个完整月的平均净现金消耗。不满足计算条件时保留服务返回的状态，不给出看似精确的期限。

将资金变化追溯到实际记录，再提出投入、延后或降低固定支出等有限方案。预测注明假设、基准和情景；预计支出不会自动成为付款。通过当前合同保存修订或报告，复用回执，不手动递增公司快照版本。
