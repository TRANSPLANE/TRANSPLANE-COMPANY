# 周期复盘与经验沉淀

明确本次周报或月报的期间、截止日及要回看的决策。读取当时的选择、精确结果引用和经营快照，再查看当前状态；不要用今天的余额或后来修订的结果替代过去的依据。

对照事前目标、已保存意向、实际或模拟行动、资金变化和取得的结果。说明哪些事实支持判断，哪些是分析，哪些仍是情景假设。失败结果也应保留；不为补齐故事而编造原因、客户或收益。

从变化中选出会影响下一周期的事项，提出有结果目标、承诺范围和依据的经营选择。日常工具步骤由 Agent 客户端管理。保存报告时固定期间与数据截止；采用当前快照可让平台自动确定基线，回看过去则显式使用历史快照。

只有用户要求总结长期经验时，才创建或修订经验 Skill。把材料转化为可执行规范：何时使用、需要哪些输入、怎样判断、采取什么做法、何时不适用、什么变化需要复核。保留支持它的决策、报告或资料的精确版本。

单次经历支持的范围有限。模拟结果可以形成主持或实验设计经验，不能直接证明真实市场规律；客户或行业特定的做法应保留适用条件。不要将账号、客户个人信息、一次性状态或访问凭据写成长期通用指令。

修订已有 Skill 时先读取该 Skill 的版本，保留历史并处理冲突。没有新增可迁移判断时，保留原规范即可。用户未要求持久学习时，将本次结论留在报告中。
